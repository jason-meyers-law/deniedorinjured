# Per-article research checklist

Run this for every Florida legal article before its `draft` flag
clears (PLAN.md §26, §34). The frontmatter's `legalReviewDate` is set
only by the reviewing attorney.

## Before drafting

- [ ] The exact user question is written down (one question per page).
- [ ] Current Florida law confirmed from primary sources: statute text
      at leg.state.fl.us (current-year version, not a cached summary),
      controlling Fla. S. Ct. / DCA opinions, rules, standard jury
      instructions as applicable.
- [ ] Every statute/case cite pulled and read — never cited from memory
      or from another firm's site.
- [ ] SERP/AI landscape checked: what ranking pages answer, what they
      miss, what first-hand insight this firm can truthfully add.

## Drafting

- [ ] Follows the standard template (PLAN.md §7): direct 2–4 sentence
      answer first, checklist, Florida rule, exceptions, evidence,
      insurer perspective, example (clearly hypothetical), process,
      when-to-get-a-lawyer, related links, sources, author block, CTA.
- [ ] No superlatives, no fee/result claims, no fabricated anecdotes,
      statistics, or "insider" observations.
- [ ] Insurer-perspective content drawn from Jason's actual experience
      (he supplies or approves it), not speculation.

## Before clearing `draft`

- [ ] Attorney (Jason Meyers) reviewed legal accuracy, tone, ethics,
      experience claims, and CTA wording.
- [ ] Every source re-verified as of the review date; `legalReviewDate`
      set in frontmatter by/for the reviewer.
- [ ] Internal links: parent hub, 2–5 related answers, relevant
      practice page, bio where relevant. Descriptive anchors.
- [ ] Title/H1/meta unique; description written for humans.
